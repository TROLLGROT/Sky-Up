# Sky Up
Offline star-finder for Android. Point the phone at the sky; the sky view follows the fused gyro/accelerometer/magnetometer rotation vector (adaptive smoothing, magnetic-declination correction by GPS position). Tap an object for details.
Sun, Moon, 7 planets (JPL approximate Keplerian elements) and 46 bright stars, all computed on-device. Build: GitHub Actions -> Artifacts -> Sky-Up-debug-apk.
